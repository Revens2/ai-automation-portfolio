FIELD NOTES / 10

Dix autres briques, et pourquoi elles existent.

NOTE 01 / PUBLIC

convia-sanitize

Conversation → RAG, sans recopier les secrets. Un manifeste détecte les versions à traiter ; rédaction des secrets et publication aval sont séparées par une demande durable. Une défaillance de copie n'est pas déguisée en succès.

Limite : La rédaction réduit les risques sans garantir une anonymisation parfaite.

PUBLICGitHub ↗
NOTE 02 / PUBLIC

llm-wiki

Du brut au wiki vérifiable. Extraction en sources, entités et concepts ; ingestion incrémentale tolérante aux quotas ; lint R1–R24.

Limite : Le découpage lié au TPM ne prouve aucun gain de fenêtre de contexte.

PUBLICGitHub ↗
NOTE 03 / PUBLIC

pr-reviewer

Relecture sémantique de PR en conteneur. Poller GitHub, snapshot en lecture seule, modèle isolé, statut consultatif.

Limite : Une revue IA ne remplace pas CI, tests ou protection de branche.

PUBLICGitHub ↗
NOTE 04 / PRIVATE

brave-devtools-mcp

Contrôler Brave sans exposer directement CDP. Passerelle Rust, authentification OAuth, permissions d'observation et d'écriture distinctes.

Limite : Architecture privée ; aucune sécurité absolue revendiquée.

NOTE 05 / PRIVATE

activitywatch-stack

L'activité devient un contexte exploitable. Capture Windows → agrégation/rédaction → MCP en lecture seule → notes quotidiennes idempotentes.

Limite : Les coupures ont révélé des pertes possibles d'événements.

NOTE 06 / PRIVATE

wisperfiou

Dictée Windows native en Rust. Raccourci clavier, détection de silence, transcription Whisper distante, insertion dans le champ d'origine.

Limite : Le comportement hors ligne demande une nouvelle vérification.

NOTE 07 / PUBLIC

mcp-framework-rs

Le socle commun des serveurs MCP. Composants Rust réutilisables : transport, authentification, cycle de vie et observabilité.

Limite : Bibliothèque d'infrastructure, pas une application utilisateur.

NOTE 08 / PUBLIC

excalidraw-mcp-gateway

Dessiner via MCP sans perdre les fichiers. Passerelle OAuth avec outils distinguant lecture et écriture, stockage de dessins Excalidraw persistants.
